nl2pbip — Pipeline architecture

One natural-language prompt → a complete Power BI Project (.pbip), TMDL-validated and PBIR-bound.

Deterministic core

  • • FK inference, data profiler, schema.org, prompt polisher — all run before any LLM call. Free of API round-trips.
  • • Writers (TMDL, PBIR, OPC packager) emit deterministic artefacts. Same plan + same seed → byte-identical output.
  • • Validators (PBIR, plan-payload, cardinality) run on every CI push; cross-server test gates Microsoft's TOM parser.

LLM in the loop

  • • StructuredLLMClient is a thin wrapper — swap providers via NL2PBIP_LLM_PROVIDER or the --provider flag.
  • • Custom / local endpoints (Ollama, vLLM, LM Studio) work via the OpenAI-compatible custom provider.
  • • TokenBudget guards max_cost_usd; per-attempt spend is recorded on the ReflectiveTrace.

Safety gates

  • • PromptPolisher redacts secrets + PII before the prompt leaves the process; provenance recorded on every attempt.
  • • MCP bearer-auth middleware validates Authorization on every streamable-http request.
  • • CI: ruff, black, mypy --strict, vulture, 1082 pytest cases, cross-server round-trip. No silent failures.
